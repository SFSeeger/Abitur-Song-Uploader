# Abitur Song Uploader

The Abitur Song Uploader is a web application designed to manage all requirements for a graduation be it managing the songs for each person,
voting on a theme week or managing the questionnaires for the graduation news paper. 

## Installation

Follow the guide in the [wiki](https://github.com/SFSeeger/Abitur-Song-Uploader/wiki). If there are any problems, feel
free to create a bug ticket.

## Development

### Installation

please create a `.env` file using the `.env.example`.
then simply run

```bash
docker compose up
``` 

to start server.
